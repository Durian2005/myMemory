## 项目简介

myMemory 面向中老年口述记录者，帮助用户将口述素材转换为文字，经 AI 辅助整理为传记初稿，再在线编辑并导出文档。当前文档描述产品范围、用户场景、数据结构和页面交互设想，不代表功能已经实现。

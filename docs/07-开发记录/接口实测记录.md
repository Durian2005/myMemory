## 六、端到端（真实点击，不是直调接口）

CDP 驱动浏览器 + `--use-fake-device-for-media-stream` 模拟麦克风，10 步全过：

1. 首页空态 → 2. 新建页空标题提示 → 3. 创建并进入录音页 → 4. 录 2 秒并试听 → 5. 确认入库自动转写 →
6. 进入生成页 → 7. 生成初稿 → 8. 编辑并保存 → 9. 导出 DOCX → 10. 返回列表显示「已完成」：**10/10 通过**。

## 七、降级验证（后端关闭）

| 场景 | 期望 | 实测 |
|---|---|---|
| 顶部栏状态 | 显示「本地模式」 | ✅ |
| 新建记录 | 不因后端不可用而卡死 | ✅ 本地兜底创建，提示「后端未连接，记录已保存在本机」 |
| 录音 / 编辑 / 保存 | 正常可用 | ✅ |
| 转写 | 给可重试的业务错误 | ✅ 标「转写失败」并显示原因与「重试转写」 |

> 已知偏差：技术方案写「本地模式下导出仍可用」，但本轮导出由后端拼 DOCX，后端不可用时导出会失败并提示重试。
> 该项已列入后续待办，不在本轮三个子任务范围内。

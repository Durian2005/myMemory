线框约定

  • 低保真定位：只表达位置、层级、尺寸与状态，不追求视觉。灰色块与虚线框均为占位，不代表最终样式。
  • 暖调而非冷灰：配色沿用《UI 设计规范 v1.0》的暖色 Token（奶油白 #FDFAF5、米白 #F7F1E8、浅驼 #E3D8CC、暖木 #B4785A、暖褐黑 #3D332C），避免线框与高保真阶段出现冷暖断层。
  • 编号标注：页面内带数字的圆点与下方「标注说明」一一对应，用于在评审时逐条核对。
  • 状态覆盖：每页在主视图之外单列变体，确保空态、加载态、异常态不会在实现阶段漏做。
  • 无外部依赖：全部为单文件静态 HTML，内联样式，离线可直接双击打开；不含任何真实音频或个人内容。
评审建议：本轮需确认的是信息层级与流程顺序，不是好不好看。请重点看三处 —— P3 录音页的「圆钮 + 次级操作 + 底部确认」三分结构是否顺手；P4 的「原文 / 润色」两区分离是否清晰；P5 的纯文本编辑是否符合「不提供富文本」的约束。这三处定了，第三步的高保真就是照着画。

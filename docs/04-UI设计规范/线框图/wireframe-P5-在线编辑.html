标注说明

  • 1标题输入框：18px 正文尺寸，高 56px，可随时修改，与 P2 的标题同源。
  • 2正文编辑区：普通文本域，不提供任何富文本工具栏（技术方案 9.6 明确要求）。这里刻意把「不提供」摆在界面上，避免实现时误加编辑器。

离页确认弹窗说明

  • 4存在未保存改动时离开页面即触发（技术方案 9.6）。弹窗含三个动作：放弃修改（文字按钮，危险语义）、取消（次按钮）、保存并离开（主按钮）。弹窗关闭后焦点回到触发位置。

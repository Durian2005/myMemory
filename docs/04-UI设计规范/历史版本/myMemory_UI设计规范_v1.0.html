1. 说明

1.1 本规范的作用

本文档把《技术方案与页面原型规划（人工修改稿）》中以文字形式给出的界面约束（主色与间距统一、按钮有效区域不小于 48px、正文字号不小于 16px、状态需文字提示、危险操作二次确认等），固化为可直接执行的设计变量与组件规则。

后续的线框图与高保真视觉稿，均以本文档定义的 Token 与组件规格为准，不再另行约定颜色、字号与尺寸。

1.2 设计原则

  1. 语音优先：录音是核心动作，在任一相关页面都应是视觉权重最高的元素。
  2. 一页一主操作：每页只允许一个主按钮，其余操作以次级或文字按钮呈现。
  3. 状态可见：任何耗时或状态变化都必须有文字说明，不允许只用颜色或动画表达。
  4. 大而清晰：面向中老年用户，字号、间距与点击区均取下限偏大的取值。
  5. 克制装饰：不使用插画、渐变背景与装饰性动画，避免干扰主流程。

1.3 与其他文档的关系

文档关系

2. 设计 Token

2.1 色彩

全站配色统一采用低饱和度暖色系，由米白、奶油、浅驼、暖木、淡陶土等色构成，营造温馨柔和的视觉氛围。背景、卡片、按钮、文字、边框全部取自同一暖色体系，保持整体协调。

配色禁令：禁止使用大红、大紫等高饱和鲜艳色；禁止夸张渐变、霓虹色与强对比撞色。所有语义色同样以低饱和暖色表达，不引入冷色。

2.4 字体

  • 中文优先：-apple-system, "Microsoft YaHei", "PingFang SC", sans-serif。
  • 数字与时长：与正文同字体，必要时用 font-variant-numeric: tabular-nums 保持等宽。
  • 不使用衬线字体与手写体，避免中老年用户阅读负担。

3. 组件规范

3.1 按钮

类型背景 / 文字高度使用场景
主按钮（Primary）#B4785A / 奶油白 #FDFAF556px每页仅一个：开始录音、保存内容、导出文档
次按钮（Secondary）奶油白 #FDFAF5 / #9E6650，1px 浅驼边框48px暂停、继续、播放、进入编辑
文字按钮（Text）无底色 / #7A6A5E48px删除、取消、返回等低频操作
危险按钮（Danger）#B5675A / 奶油白 #FDFAF548px仅出现在二次确认弹窗内
  • 禁用态：不透明度 40%，并保留文字说明禁用原因。
  • 加载态：按钮文字替换为「处理中…」，宽度不变，禁止重复点击。

3.2 录音按钮（核心组件）

录音是本产品的核心动作，单独定义规格：

状态外观文案
未开始直径 96px 圆钮，主色实心，居中开始录音
录音中圆钮变为停止图标，外圈显示 3s 呼吸动效；实时显示时长正在录音 · 00:42
已暂停圆钮回到主色，旁边出现「继续」次按钮已暂停
已结束待确认圆钮隐藏，改为「重新录制」（文字按钮）与「确认录音」（主按钮）录音时长 03:15
失败圆钮置灰，下方显示原因与重试入口录音失败，请检查麦克风后重试
约束：录音中必须有文字状态提示，不能只靠动效；未点击「确认录音」前不得自动进入转写。

3.3 状态提示

类型样式使用场景
行内提示16px 正文 + 左侧 4px 语义色竖条页面内的持续状态，如「正在录音」
Toast顶部居中，2.5 秒自动消失，含文字保存成功、记录已删除
错误块暖调警示底色 + 「原因 + 下一步动作」两行转写失败、存储不足
确认弹窗16px 圆角，标题 + 说明 + 两个按钮删除记录、放弃未保存内容、重新录制

文案统一遵循「原因 + 下一步动作」句式，例如「麦克风未授权，请点击浏览器地址栏的锁图标允许后重试」。

3.4 表单与输入

  • 输入框高度 56px，内边距 16px，边框 1px --color-border，聚焦时边框变主色并加 2px 外发光。
  • 标签置于输入框上方，16px，不使用 placeholder 代替标签。
  • 编辑区为普通文本域，不提供富文本工具栏（与 8.5 节一致）。
  • 校验失败时输入框下方显示 16px 错误文字（使用暖调危险色 #B5675A），不使用深红边框作为唯一提示。

3.5 卡片与列表

  • 记录卡片：奶油白底 #FDFAF5、12px 圆角、一档投影、内边距 24px；卡片内自上而下为标题、更新时间、状态标签。
  • 卡片右下提供「继续编辑」次级入口，左侧提供删除文字按钮。
  • 列表项间距 16px，卡片间不使用分割线。

3.6 空态

统一为「一句话说明 + 一个主操作」：图标不强制，文案如「还没有口述记录，可以先创建一条记录」，下方直接给出「新建口述记录」主按钮。

4. 页面布局规范

4.1 整体骨架

区域规格说明
顶部栏高 64px，白底，底部 1px 分割线左侧返回入口，中间当前记录标题，右侧服务状态指示
内容区最大宽 960px，左右内边距 24px，上下 32px所有页面统一
底部动作区高 80px，白底，顶部 1px 分割线，含唯一主按钮随内容滚动，页面短时吸附底部

4.2 主按钮位置约定

  • 主线流程页面（P1–P5）：主按钮固定在底部动作区，保证始终可见。
  • 弹窗类页面（P6 导出确认）：主按钮位于弹窗底部右侧。
  • 任何情况下，主按钮不得出现在页面中部内容流中。

4.3 响应式断点

断点行为
≥ 1024px内容区居中 960px，两侧留白
768px – 1023px内容区宽度自适应，内边距降为 16px
< 768px不承诺支持；页面显示「请使用电脑浏览器打开以获得完整功能」

与 6.4 节兼容性需求一致：界面按最小宽度 768px 设计，移动端不做适配。

# myMemory 使用教程

> **重要说明**：当前版本尚未接入真实的 AI 语音转写与文本生成，这两步返回的是内置模拟引擎的占位内容，
> 页面上也有明确标注；**除此之外的其他功能都可正常使用**（新建、录音与试听、文字素材、编辑保存、
> 导出 Word、本地持久化、断网降级）。
>
> 更多项目更新请见项目仓库：<https://github.com/Durian2005/myMemory>

---

## 方式一：用免安装分发版（推荐，别人拿到就能用）

1. 解压 `myMemory-分发版-win64.zip`
2. 双击 `启动 myMemory.bat`
3. 等 3 秒，浏览器自动打开 `http://127.0.0.1:5210`
4. 用完关掉黑窗口即停止服务

不需要安装 .NET / Node / 数据库。首次运行可能被 SmartScreen 提示，选「更多信息 → 仍要运行」。

## 方式二：从源码跑（开发用）

```bash
# 终端 1：后端
cd myMemory-app/server && dotnet run

# 终端 2：前端
cd myMemory-app/web && npm run dev
```

浏览器打开 `http://localhost:5173`。关闭：两个终端各按一次 `Ctrl + C`。

## 八步走完一次完整流程

### ① 打开首页
标题「我的口述记录」、右上角状态标签（服务正常）、中间空态提示、底部大按钮「新建口述记录」。

### ② 先故意点错一次
点「新建口述记录」→ 什么都不填，直接点「开始录音」。
应出现红字「请先填写记录标题」，输入框变红，光标自动回到输入框。
（旧版本按钮直接变灰，提示永远不出现——这是本轮修过的缺陷。）

### ③ 正常创建
填「我在南昌的童年」→ 点「开始录音」→ 自动进入录音页。

### ④ 录音
点中间 96px 圆钮，浏览器询问麦克风权限时选**允许**。计时器开始走，圆钮变红色方块。
录 5～10 秒后点「结束本段」，出现「录音已完成」和播放器，可试听；不满意点「重新录制」。

### ⑤ 确认并转写
点「确认这段录音」。顺序是**先存进本机数据库，再上传转写**（约 1 秒）。
成功后片段卡片显示「已转写」和一段文字（模拟引擎的占位内容，会明确标注）。

> 不想录音：同一页有「不方便录音？可以直接打字」，效果等价。

### ⑥ 生成初稿
点「下一步：生成初稿」。若一段素材都没有，会提示「还没有可用的口述内容」——这是有意的拦截。
进生成页点「生成初稿」（约 1 秒）。页面结构：警示条 → 转写进度 → 原始转写（只读）→ AI 初稿（可编辑）。

### ⑦ 编辑并保存
在初稿框里加一句，比如「那年夏天特别热」→ 点「保存初稿」→ 出现「已保存到本机」。
改完不保存就返回，会弹「初稿还有未保存的修改，确定要离开吗？」。

### ⑧ 导出并回列表
点左下「导出文档」→ 确认弹窗摊开标题、字数、片段数、格式、预计文件名、摘要 → 点「导出文档」→ 下载 docx。
回列表：卡片显示「已完成」、共 1 段录音。**按 F5 刷新，数据还在。**

## 降级验证（可选）

把后端关掉（或直接关掉黑窗口），刷新首页：
- 右上角变「本地模式」
- 仍能新建（提示「后端未连接，记录已保存在本机」）
- 录音、打字、编辑、保存全部正常
- 点转写会失败，片段标「转写失败」并给出原因和「重试转写」，**音频不会丢**

重启后端后点「重试转写」即可恢复。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面能开但一直「本地模式」 | 后端没起 / 黑窗口被关 | 重新双击启动脚本 |
| 点录音没反应 | 麦克风被拒 | 地址栏锁图标 → 网站设置 → 麦克风「允许」→ 刷新 |
| 端口 5210 被占用 | 已有一个实例在跑 | 直接打开 `http://127.0.0.1:5210` |
| 导出点了没反应 | 正文为空，或浏览器拦截下载 | 正文为空会提示；拦截看地址栏右侧图标 |
| 换浏览器列表变空 | 数据存在各浏览器自己的 IndexedDB | 正常现象，不是丢数据 |

## 给老师演示的 3 分钟脚本

1. 开首页：「新用户看到的是空态提示」。
2. 新建页**故意空提交**：「参数校验是生效的」。
3. 录 5 秒、试听：「音频先存本地再上传，转写失败也不丢」。
4. 进生成页：「左边原文只读、右边初稿可编辑，AI 不覆盖原始讲述」。
5. 改一句、保存：「保存是显式的，不会偷偷保存」。
6. 导出：「后端直接拼 OOXML 生成 docx，不依赖 Office」。
7. 回列表：「状态变成已完成」。
8. 收尾：「转写和生成目前是本地模拟引擎，契约和页面都按真实服务做好了，换供应商只改一个实现类」。

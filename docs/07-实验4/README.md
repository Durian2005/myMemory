# 实验4：分模块 AI 代码开发（V 模型编码实现）

本目录记录 myMemory 项目在「实验4 · 分模块 AI 代码开发」中的开发与评审过程。
按课程要求，本轮只提交两项材料（Word 文档与学生信息不在本仓库中）：

1. 填写的 Word 文档（含学生信息，**不随仓库公开**）
2. 迭代后的最终版任务看板 → `../06-任务看板/myMemory_任务看板_v2.4.html`

## 一、本轮完成范围

作业要求把项目全部细粒度垂直切片逐个开发闭环。本轮完成三项，并超额补上导出：

| 子任务 | 内容 | 后端接口 | 前端页面 |
|---|---|---|---|
| A | 新建传记项目 | `POST /api/projects` | P1 记录列表、P2 新建记录 |
| B | 素材上传录入 | `POST /api/transcriptions` | P3 录音与文字素材 |
| C | AI 传记生成与编辑 | `POST /api/polish` | P4 原文只读 + 初稿可编辑 |
| D（超额） | 文档导出 | `POST /api/exports` | P6 导出确认弹窗 |

源码在同仓库 `app/` 目录。

## 二、人工初审

每个子任务完成后都做了人工初审，按课程给的 5 个检查点逐项核对，
发现问题就让 AI 修复并复测。完整记录见 `人工初审记录_完整版.md`。

本轮发现的主要问题：

- 参数校验被 `disabled` 按钮架空，「请先填写记录标题」永远触发不了
- 卡片元信息 14px 低于规范下限、状态标签深底白字、Toast 遮挡顶部标题
- 音频先上传后入库，转写失败会丢录音
- 写 IndexedDB 时把 Vue 响应式代理对象直接存进去，浏览器报 `could not be cloned`
- 模拟引擎删除口语填充词后留下「。，」标点残渣

## 三、验证

- `dotnet build` 0 警告 0 错误；`npm run build`（含 vue-tsc）通过
- 五个接口的分支实测：见 `接口实测记录.md`

## 四、说明：暂未接入真实的 AI 转写

本轮没有接入真实的语音识别与文本生成服务，这两步使用内置的本地模拟引擎：

- 链路是真实的：上传、参数校验、业务错误码、落库、导出全部真实执行
- 只有「音频→文字」和「文本润色」两步是占位内容，界面上有明确标注
- 其他功能（新建、录音试听、文字素材、编辑保存、导出、本地持久化、断网降级）均可正常使用

接入真实服务时只需替换 `app/server/Services/Providers/` 下的实现类，前端与接口契约不用改。

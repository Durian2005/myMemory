六、口径说明（与详细设计文档的差异）

1. 新增 POST /api/projects。《后端模块划分清单》5.1 与《API 接口文档》1.3 判定「新建传记项目」为前端本地动作、不产生后端接口； 实现阶段需要该动作具备后端接口，故新增。该接口仍遵守「后端不持久化用户数据」的既定决策：只做准入校验与结构规范化，记录落盘仍由前端写入 IndexedDB。 新增错误码 MYM_1010 / 1011 / 1012 接续既有编号，两份文档已同步补注。
2. 子任务 B、C 不新增接口。素材上传转写复用《API 接口文档》的 I02 POST /api/transcriptions； AI 生成复用 I03 POST /api/polish。两者的入参、返回与业务错误码均按既定契约实现，未作改写。
3. T-04 导出与 T-07 分发版均为超额完成。T-04 对应《API 接口文档》的 I04，为形成「录入→生成→导出」完整闭环而补充； T-07 为让项目在别人机器上「解压即用」而增加的发布形态，不属于本轮三个子任务范围。
4. 外部智能服务的当前状态。转写与生成通过 ISpeechToTextProvider / IGenerationProvider 注入， 当前注入的是本地模拟实现（local-stub），链路真实、内容为占位，界面与使用说明中均有标注。 接入真实服务时只替换实现类，接口契约与前端无需改动。
